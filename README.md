# Perro Cazador (Fabric, Minecraft Java 1.21.11)

Tu lobo domado (solo el que elijas) caza animales cerca de ti y te entrega el botin y experiencia.

## Uso
- Agachate y haz clic derecho sobre tu lobo domado con un hueso en la mano. Repite para quitarle el modo cazador.
- Caza cerdos y ovejas adultos sin nombre, en todos los chunks cargados.
- El botin (carne, cuero, plumas...) va directo a tu inventario (si no cabe, cae a tus pies). Recibes 1-3 de XP por presa.
- Si lo mandas sentarse o baja del 40 % de vida, deja de cazar. Si esta defendiendote, no interfiere.

## Instalacion
Pon el .jar en `mods/` junto con Fabric API 0.141.6+1.21.11 y Fabric Loader 0.20.1 o superior.

## Compilacion
GitHub Actions compila al subir cambios: pestana Actions > ultima ejecucion > artefacto `perro-cazador`.
